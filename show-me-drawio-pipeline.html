开关 / 设置 入口 UI 可用值 影响链路
供应商 / 模型 / API URL 设置 ModelComboBox openai-reasoning · openai-compatible · deepseek-native · anthropic · gemini；modelName；apiUrl（按供应商标识带默认 URL） 决定 createModelFromConfig 选哪个 AI SDK 工厂；capabilities.supportsVision 决定能否发图；影响模型推理表现（推理链 / 工具调用轮次 maxToolRounds 默认 20）。
Skill · 主题风格 设置 SkillButton modern · academic · minimal · custom（custom 用 customThemePrompt） 写入 systemPrompt 的 {{theme}}，控制图表视觉风格提示（配色、形状、连线走线、版式）。
Skill · 配色主题 设置 SkillButton default · blue · green · warm · cool · grayscale · earth · none 写入 {{colorTheme}}，提供 fillColor/strokeColor 配对色板。优先遵从用户自定调色板，否则用所选色板。
Skill · 知识库 设置 SkillButton general（必选）· basic · misc · uml · aws · azure · gcp · network 写入 {{knowledge}}，注入可用图形 ID 与样式映射（形状库 + 云厂商图标）。
画布上下文 默认开 CanvasContextButton 开启 / 关闭 数据路径：开启则在用户消息注入 <drawio_status>、<user_select>（仅 Electron）、<page_scope>；提示词路径：后端将 {{canvas_context_guide}} 替换为 CANVAS_CONTEXT_GUIDE（教导模型如何理解这些标签）。关闭则两路都为空，省 token。
布局检查 默认开 CanvasContextButton 开启 / 关闭 提示词路径：后端将 {{layout_check_guide}} 替换为 LAYOUT_CHECK_GUIDE；执行路径：drawio_edit_batch 成功后运行 runLayoutOverlapCheck，检测连线与元素重叠，返回 warnings + layout_check（引导模型改连线而非移节点）。
页面范围 默认全选 PageSelectorButton 多选页面（0 到全部，发送时为空则拦截提示） 非全选时：① 注入 <page_scope> 标签到用户消息，提供每页 XPath；② 工具执行经 getAllowedPageIdsOrNull 只操作选中页面，并禁止匹配全局节点（如 <mxfile>）。MCP 场景自动跳过过滤。
自动版本快照 默认开 VersionSettingsPanel
（存储设置 version.autoVersionOnAIEdit）		 开启 / 关闭 开启时，AI 工具执行前调用 createAutoVersionSnapshot 建历史版本快照。若尚无主版本：先补建默认主版本 1.0.0，并跳过本次子版本创建（避免内容相同触发 4021“无差异”错误）；已有主版本则按 getNextSubVersion 递增子版本。
关键机制提示：本应用是「前端执行工具」架构（v1.2）。后端 /api/ai-proxy 只做代理与提示词组装，toToolSet 刻意不提供 execute，因此工具真正执行发生在浏览器/Electron 渲染进程，由 frontend-tools.ts 操作真实 DrawIO XML。多轮工具调用靠 sendAutomaticallyWhen = lastAssistantMessageIsCompleteWithToolCalls 循环触发，直到 finishReason !== "tool-calls" 或出现致命工具错误。
